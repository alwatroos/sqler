## Version policy

- Verify the latest stable version on crates.io (and read the release notes) before adding or bumping
  any dependency. Never pin a version from memory.
- Stable releases only; no pre-release versions.
- Declare each dependency once in the root `[workspace.dependencies]`; crates use `dep.workspace = true`.
- Commit `Cargo.lock`.
- Every add or bump updates this page or an ADR with the version and the reason.
- Send a User-Agent header with crates.io API requests; the API rejects requests without one.

- GPUI in the root workspace (T5, ADR-0007): `gpui-component` 0.8.0 (with `tree-sitter-sql`), `gpui` (`gpui-pre` =0.3.9) and `gpui_platform` (`gpui-pre-platform` =0.3.9) are optional dependencies of `sqler-ui` behind the feature `gui`, enabled only by `sqler-app`. `cargo deny` now sees the tree; the three MPL-2.0 exceptions and eight advisory ignores it needed are listed in ADR-0007. Versions re-checked live on 2026-10-20: no newer stable `gpui-component`, `gpui-pre` or `gpui-pre-platform` than the pinned ones, so there is no pending bump.
- `russh` 0.64.1 (T6, ADR-0013): SSH session and `direct-tcpip` forward in `sqler-tunnel`; pure Rust, so no `OpenSSH` binary and no C SSH library (`ssh2` binds libssh2). Feature `ring` only, with `default-features = false`; the default `aws-lc-rs` backend is rejected (CMake/NASM on Windows, extra licence terms in `aws-lc-sys`). `ring` needs a C compiler through `cc`, which MSVC on `windows-latest` provides. The `rsa` feature is deliberately off: it pulls in the `rsa` crate, which carries RUSTSEC-2023-0071 (Marvin timing attack, no patched version), and `deny.toml` has no ignore for it. Consequence: RSA-only host keys stay unsupported. RSA user keys work since ADR-0018 through a signer over `ring` (`russh::Signer`), still without the `rsa` crate; the `deny.toml` `[bans]` entry keeps `rsa` out. No licence exception was needed (all crates in the `sqler-tunnel` tree are on the allow-list). `cargo deny check` reports duplicate-version warnings for RustCrypto crates (`multiple-versions = "warn"`). `russh` logs through the `log` crate; no logger is installed and it does not log credentials. `rand` 0.10.3 and `tokio-stream` 0.1.19 are dev-dependencies of `sqler-tunnel` only.

The lexer is hand-written; `sqlparser` and `tree-sitter` are deliberately not used for completion. The bench is std-only (`harness = false`), as in ADR-0006.
